> 演示文章：用于展示文章排版、代码块、引用和表格等能力。

社交网络中的内容更像河流：它迅速出现，也迅速离开视野。个人博客则更像花园，作者可以决定种什么、如何组织，以及何时回来修剪。

## 花园不是仓库

仓库强调“保存了多少”，花园强调“事物之间如何生长”。一篇旧文章可以因为新的理解被再次修改，也可以通过标签、系列和链接，与后来写下的内容形成关系。

这也是为什么本站的文章包含 `updatedDate`：发布日期描述文章何时出现，更新时间则诚实地说明它仍在变化。

## 最小写作循环

一个可持续的工作流不需要复杂：

```bash
npm run post:new -- --title "新的观察"
npm run dev
npm run post:publish -- new-observation
npm run publish -- "发布：新的观察"
```

这四步分别对应：创建、观察、确认和交付。工具的作用是减少重复劳动，而不是替代思考。

## 让结构服务内容

标签应该描述文章横向涉及的话题，分类则说明文章最主要的归属。如果一个标签只出现一次，并且以后也不会再用，它可能只是正文里的一个关键词。

最终，真正重要的不是建立一套完美系统，而是让下一次写作比上一次更容易开始。
