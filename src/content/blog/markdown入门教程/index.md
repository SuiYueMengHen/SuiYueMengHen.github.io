# Markdown 完全指南

Markdown 是一种轻量级标记语言，让你用纯文本编写结构化的文档。它简洁、易读、易写，最终能转换成 HTML 等格式。这篇教程覆盖了最常用、最实用的语法，助你快速上手。

---

## 基础语法

### 标题
使用 `#` 号标记，数量代表层级。
```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```
一级和二级标题还可以用底线形式（不常用）：
```markdown
一级标题
=======
二级标题
-------
```

### 段落与换行
段落之间空一行。  
行末加两个空格再回车可以实现段内强制换行。

### 强调
```markdown
*斜体*  
_斜体_

**粗体**  
__粗体__

***粗斜体***  
___粗斜体___

~~删除线~~
```

### 列表
**无序列表**：`-`、`+` 或 `*` 开头。
```markdown
- 项目一
- 项目二
  - 嵌套项目（缩进两个空格或一个制表符）
```

**有序列表**：数字加点开头。
```markdown
1. 第一步
2. 第二步
   1. 子步骤
```

### 链接
```markdown
[链接文本](https://example.com)
[带标题的链接](https://example.com "鼠标悬停时显示的标题")

<https://example.com>   <!-- 自动链接 -->
```

### 图片
```markdown
![替代文本](图片链接)
![示例](https://example.com/image.png "图片标题")
```

### 代码
**行内代码**：用反引号包裹  
`` `代码` ``

**代码块**：用三个反引号（或四个空格缩进）
```markdown
\```python
print("Hello, Markdown!")
\```
```
效果：
```python
print("Hello, Markdown!")
```

### 引用
```markdown
> 这是一个引用。
> 可以跨多行。
>
> 嵌套引用：
>> 内层引用
```

### 分割线
```markdown
---
***
___
```

## 扩展语法（GFM 等）

### 表格
```markdown
| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容   | 内容   | 内容   |
| 行     | 行     | 行     |
```
效果：

| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容   | 内容   | 内容   |
| 行     | 行     | 行     |

### 任务列表
```markdown
- [x] 已完成任务
- [ ] 待办任务
- [ ] 另一件事
```

### 脚注
```markdown
这是一个带脚注的句子[^1]。

[^1]: 这是脚注的内容。
```

### 删除线
```markdown
~~这段文字被删除~~
```

### 自动链接
直接写 URL 或邮箱，会被自动识别：
```markdown
https://example.com
user@example.com
```

### Emoji（部分平台支持）
```markdown
:smile: :heart: :+1:
```

### 内嵌 HTML
Markdown 支持直接写 HTML，适合需要复杂排版的场景：
```html
<kbd>Ctrl</kbd> + <kbd>C</kbd>
```
效果：<kbd>Ctrl</kbd> + <kbd>C</kbd>

## 书写建议

- **简洁清晰**：尽量用最少的符号表达结构，不过度装饰。
- **空行分隔**：段落、标题、列表、代码块前后加空行，提高源文件可读性。
- **转义字符**：如果想让符号原样显示，在前面加反斜杠 `\`。  
  例：`\*不是斜体\*` → \*不是斜体\*
