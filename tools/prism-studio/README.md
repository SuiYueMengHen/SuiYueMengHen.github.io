# Prism Studio

Prism Notes 的本地三栏写作工具：左侧内容库，中间文章工作台，右侧真实 Astro 成品预览。

- 合集按章节展示，直接拖动文章即可重排，章节号会自动连续更新。
- 分类与合集从现有数据中选择，也可当场创建；分类支持集中重命名与删除，删除后文章自动归入“未分类”。合集文章不参与分类，选择合集时分类控件会自动停用。
- 摘要使用多行编辑器；封面可以选择本地图片并调整比例、缩放与裁切位置。
- 编辑停止约 260ms 后原子保存。内嵌预览采用“稳定页面壳 + Astro 后台渲染 + DOM 局部热替换”，不会再由 Vite 整页 HMR 引发白屏或闪烁，并保留当前滚动位置。
- Studio 预览会停用外部 Giscus iframe，避免网络组件干扰编辑；评论区在正式网站上仍按原配置正常加载。
- Studio 支持持久化浅色/深色主题，实时网页预览会同步同一主题；所有输入框、标签页和下拉菜单均使用对应主题配色。
- “专注写作”可以收起文章信息区，将主要空间交给 Markdown 编辑器。
- Markdown 源码行会与右侧正文块精确双向同步；文章头尾的目录、导航和评论不参与定位，旧版预览索引会自动刷新。
- 工作区位置会持久化；移动 App 或博客目录后可从顶部“选择工作区”重新指定。
- 每分钟在工作区干净时自动快进同步 GitHub，也可以点击顶部“同步 GitHub”。
- 新建或修改的文章、合集都会显示未上传红点；Git 扫描、同步、检查、构建与上传全部在后台执行，不会阻塞编辑器。
- “发布当前文章”使用隔离路径提交，不会误带暂存区中的其他文章；推送后会核对本地与远端跟踪提交，只有真正上传成功才清除红点。
- 左侧“添加 GitHub 项目到项目页”只需输入仓库地址；项目元数据在后台读取并保存为本地快照，可作为单独内容上传。
- 点击项目时只显示专用项目信息表单，可修改名称、简介、项目标签、主页、封面、重点状态和展示顺序，不再显示文章 frontmatter 或 Markdown 编辑区。
- “上传完成”分为 GitHub 推送和 Pages 上线两阶段；只有线上 `/build-info.json` 的提交号与本次提交一致时才会显示“网站已经更新”。若文章仍是草稿，上传前会询问是否转为公开文章。
- 顶部“重新载入内容”会从当前 Git 工作区重建文章、合集、项目和预览索引，不删除本地内容。
- 支持新建、编辑和移除文章。移除的文章进入 `.prism-studio/trash`，不会立即永久删除。

```bash
python3 -m pip install -r tools/prism-studio/requirements.txt
npm run studio
```

发布依赖外部的 Node.js、npm 与 git；GitHub 项目导入额外依赖 `gh` 登录。即使 `gh` 认证失效，只要仓库的 Git/SSH 推送正常，发布按钮仍然可用。修复 API 认证可执行 `gh auth login -h github.com`。构建 macOS 应用：双击 `build-macos.command`，或运行 `cd tools/prism-studio && pyinstaller --clean --noconfirm PrismStudio.spec`。

应用会从当前目录和 `.app` 所在路径自动向上寻找 Prism Notes 仓库，并自动搜索 Homebrew 与登录 shell 中的命令；如需打开另一份仓库，可在启动前设置 `PRISM_NOTES_ROOT=/完整/仓库路径`。
